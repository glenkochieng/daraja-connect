# Daraja Connect

Mentor matching and alumni engagement platform for the Kenya Airways ecosystem: Pride Centre
alumni, current staff and former staff. Final-year capstone project, BSc Informatics and
Computer Science, Strathmore University.

## Repository layout

| Folder | Component | Status |
|---|---|---|
| `ml-service/` | Python content-based mentor recommender and FastAPI matching service | Working, see [ml-service/README.md](ml-service/README.md) |
| `server/` | Node.js / Express REST API on MongoDB | Planned (#7) |
| `client/` | React web application | Planned (#23) |
| `e2e/` | Playwright end-to-end tests | Scaffold only (#29) |

Full setup instructions will follow in #32.
